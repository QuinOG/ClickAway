# Round 11 changes (i10 → i11)

Picks came from `i11-decisions.md`. Every claim below was checked in a 100% crop of the 1440px capture.

## Regression fixed
- **Login (01):** the red S1 seal is now stamped across the gold "Competitor pass" header strip, between "COMPETITOR PASS" and "ADMIT ONE · SEASON 1". It no longer touches the headline.

## A. Armory (03): the right column
- **Swap report:** the report is a dark green instrument screen.
  - It has a bezel, four corner screws and faint scanlines.
  - The header and values are in glowing green.
  - Each new value ("112px", "16px", "2.0% / hit") sits in its own recessed black readout window.
  - Losses read in red ("−12%").
- **Part cards:** each card is a cartridge.
  - It has a ridged grip band along the top.
  - The part name is on a cream sticker label in black ink.
  - A row of gold edge-connector pins runs along the bottom.
  - The cards sit in a recessed dark tray.
  - The installed part has a green outline.
  - Both rows of cards fit above the fold.

## B. Ladder (06)
- **Control rail:** the board tabs, the search field and the Top Players / Around Me toggle now sit in one recessed rail in a single row. The old three-row stack is gone.
- **Nameplates:** each player's portrait, name and tier chip sit on a brushed-metal nameplate in the row's colour:
  - gold for #1;
  - silver for #2;
  - bronze for #3;
  - cyan for you;
  - steel for everyone else.
- **Engraved names:** names are dark ink with an engraved highlight and shadow.
- **Bezels:** portraits sit in a two-ring metal bezel.

## C. Duels (07)
- **Counter top:** the "Stake a run" counter is wood with visible streaked grain (an SVG turbulence texture) under a warm lamplight pool centred on the tokens.
- **Front edge:** the counter has a bevelled front lip, with a light top edge, a darker face and a black underside.
- **Shadows:** each run token casts a contact shadow on the wood.
- **Ledge:** the taunt and Send ledge below uses the same grain in a darker stain.

## D. History (08)
- **Score trend:** the chart is now a plotted line.
  - Each run is a glowing dot joined by a 3px line in the mode's colour (gold for Ranked).
  - The area under the line is filled.
  - Dashed drop lines run from each dot to a solid baseline.
  - A grid runs behind.
  - The score readouts float above each dot.
- **Highlights:** the two plaques are brushed brass, with a visible streaked grain.
  - Each has a strong bevel: a light top-left edge, a dark bottom-right edge and a double inner rim.
  - Each has a round brass emblem on the left: a star on "Latest run", a triangle on "Ranked surge".
  - The text is engraved, with a light and a dark edge.

## E. Profile (05)
- **Scouting report:** the report now runs down to the bottom of the Competitor card, so there is no empty space below it.
- **Recent form:** the seven recent-form coins are about 30% larger.
- **Trophy shelf:**
  - The per-trophy bars are replaced by one continuous wooden shelf, with grain, a light front edge and a shadow, running under all five trophies.
  - A warm spotlight falls on each trophy from above; the earned trophies and the next one are brightest.
  - The trophy medals are about 20% larger.
