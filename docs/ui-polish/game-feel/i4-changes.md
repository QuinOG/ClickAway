- 08 History: each round is a match ticket with a mode-coloured stub, a punched notch, a perforated tear line, an emblem medallion on the stub and a rotated rubber-stamp result (+14 RR / NO CHANGE). Highlight cards are gold-edged record plaques with metallic numbers. Climb pedestals are now coloured by mode.
- 10 Settings: a gold ribbon title, a red carved close button, and a saturated gold APPLY that no longer reads as disabled.
- Global: the cyan corner notches inside panels are removed, and repeated items (history tickets, highlight cards, help blocks) no longer wear the gold-bracket frame. Brackets are reserved for top-level panels.
