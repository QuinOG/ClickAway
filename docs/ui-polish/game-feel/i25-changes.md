# Round 25 changes (i24 → i25) — FULL READ

Every claim below was checked in a 100% crop and passed a blind before/after check (ladder +1.0, spec sheet +0.5). Screens 06, 15 and 18 changed; every other file in i25 is a byte-for-byte copy of i24.

## A. Ladder (06)
- **Podium character stages:** each of the top three stands as a large, frameless illustrated bust above their plinth (no small circular portrait frames); the winner's bust is lit by the spotlight with a crown above.
- Plinths are shorter, so the busts dominate; names, tiers and RR sit between bust and plinth without overlapping neighbours.

## B. Ladder hover card (15)
- Only the podium visible behind the card changed (the new character busts from A); the card itself is identical to i24.

## C. Armory spec sheet (18)
- **Dials on the blueprint:** the seven performance dials no longer sit in individual bordered cards; they are mounted directly on a shared blueprint grid inside one framed panel, each with its label and value beside it.
- Dashed guide lines run under each instrument row, linking the dials into one assembly.
- The field record (ruled entries, red margins, stamped labels, green ticks) is unchanged.

## Not shipped
- **Hover card bust above the ring (15):** a smaller socket ring with the helmet raised above it was built, then reverted after the blind check judged the i24 portrait better by 0.4.
