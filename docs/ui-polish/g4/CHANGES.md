# Round 3 changes (g3 -> g4)

Frame set is now 11 (the separate "rewards settled" screen was removed — rewards live on the results screen).

Gameplay loop
- Results is one screen: coins chip shows the new running total; XP bar + level progress; a featured Next Unlock card with the part's illustrated icon, level badge, its benefit text, and an Equip/Preview action into the Armory. "View Rewards" step removed; secondary action is now "Change Mode".
- Live miss: the dark-on-red "STREAK LOST" stamp is gone; bright white "N STREAK LOST" text (shows the streak length lost) under the red penalty.
- Failure frame vs heat frame are now distinct: a miss gives a hard red rim + inner red flash; high-streak heat is an amber outer glow only.
- Next-multiplier meter enlarged: framed panel, bigger pips, gold "×N in K" label.

Armory
- Rig columns rebalanced; slot part names wrap instead of truncating ("Ti…" fixed).
- Powerups are full-width rows: key, icon, full name, and charge timing.
- Installed part in the parts list collapses to a compact baseline row at the top.
- Distinct illustrated silhouettes for each part (new Rapidfire, Iron Nerve, Surge, Flashpoint icons), used in the rig sockets, part cards, unlock wall, and the results unlock card.
- Compare bench and unlock wall open below the top nav, with a pinned header and internal scroll; unlock wall gains category tabs (All / Tempo Core / Streak Lens / Power Rig / Power Tools).
- Test-run results: labelled "Run N", show the build name + mode ("same parts both runs"), column headers Run N-1 / Run N, and a Score row.
