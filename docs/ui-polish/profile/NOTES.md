# Profile polish log

Round notes for the Profile screen. They're kept here, not in `HANDOFF.md`, so this branch never edits the file other polish work appends to.

- **Council 1** (`council-1/`, brief in `council-brief.md`): baseline screenshots, top to bottom.
- **p01:** Achievements read as tiered medals. Each tile shows its category's illustrated emblem on a medal whose metal steps up with each milestone (bronze, silver, gold, platinum, diamond; masters get a crown on gold/violet). A ring around the medal fills with progress, and locked medals carry a lock pip. Categories that fit on one page drop the carousel arrows and the "Page 1 / 1" footer, and the master banner spans the full row.
- **p02:** Profile has a readable type floor. Kickers and labels are 12px, and detail copy (stat captions, rank meta, form and build labels, achievement descriptions and progress) is 13px. All of it is at roughly 80% ink or more, up from 11px at 48–65%. The rules are scoped to `.profilePageCenter` so they outrank the later shared sheets without editing them.
